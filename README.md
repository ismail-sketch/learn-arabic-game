# 🌞 Сад букв — حديقة الحروف

Детская PWA-игра для изучения арабского алфавита (фусха) в игровой форме.
Растёт сад: выучил букву — расцвёл цветок, упала звезда.

Тёплый акварельный стиль, без существ/джиннов/монстров, с уважением к
мусульманскому контексту. Интерфейс на русском и арабском.

---

## Быстрый старт

```bash
npm install
npm run dev
```

Откройте в браузере: **http://localhost:5173/**

Проверка типов и сборка:

```bash
npm run typecheck   # только проверка типов
npm run build       # сборка в папку dist/
npm run preview     # локальный просмотр собранной версии
```

## Открыть приложение на телефоне через GitHub Pages

После каждого push в ветку `main` GitHub Actions автоматически собирает и
публикует приложение. Адрес приложения:

```text
https://ismail-sketch.github.io/learn-arabic-game/
```

Первый запуск публикации можно посмотреть в репозитории во вкладке **Actions**.
Когда workflow завершится зелёным статусом, откройте ссылку на телефоне.

Чтобы установить приложение как PWA:

- Android/Chrome: меню браузера → **Добавить на главный экран**;
- iPhone/Safari: **Поделиться** → **На экран «Домой»**.

Если сайт не открывается сразу после push, подождите завершения workflow и
обновите страницу. При обновлении уже установленной PWA иногда требуется
полностью закрыть приложение и открыть его снова.

## Как добавить свою озвучку

Свои записи не нужно добавлять в код и не нужно прописывать в манифесте.
Просто положите их в папку:

```text
public/audio/
```

Приложение само ищет файл по имени. Если файл найден, используется ваша запись.
Если файла нет, временно используется браузерная озвучка.

### Пример: запись буквы ج

Чтобы заменить произношение названия буквы ج, создайте файл:

```text
public/audio/letter-jeem-name.mp3
```

В этот файл запишите правильное произношение, например «جيم» без нежелательного
окончания. Для других букв используются такие же имена:

```text
letter-ba-name.mp3
letter-ta-name.mp3
letter-tha-name.mp3
letter-jeem-name.mp3
letter-haa-name.mp3
letter-khaa-name.mp3
```

ID всех букв находятся в `src/data/letters.ts`. Для текущего произношения
названия буквы используется окончание `-name`.

### Примеры слов

Для аудио слова с буквой используйте окончание `-word`:

```text
letter-ba-word.mp3
letter-ta-word.mp3
letter-jeem-word.mp3
```

Например, в `letter-ba-word.mp3` записывается слово `باب`, а в
`letter-jeem-word.mp3` — слово-пример для буквы ج.

### Приветствие

```text
greeting-ru.mp3
greeting-ar.mp3
```

В русскую запись можно записать «Привет», а в арабскую — «أهلًا».
Имя ребёнка пока произносится отдельно системным голосом, потому что оно
вводится пользователем и каждый раз может быть разным.

### Похвала и повторная попытка

```text
praise-correct-ru.mp3
praise-correct-ar.mp3
praise-again-ru.mp3
praise-again-ar.mp3
```

Примеры содержания:

```text
praise-correct-ru.mp3  → «Молодец!»
praise-correct-ar.mp3  → «أحسنتَ!»
praise-again-ru.mp3    → «Попробуй ещё раз»
praise-again-ar.mp3    → «حاول مرة أخرى»
```

### Инструкции

Можно заменить все основные инструкции:

```text
instruction-listen-ru.mp3
instruction-listen-ar.mp3
instruction-find-ru.mp3
instruction-find-ar.mp3
instruction-trace-ru.mp3
instruction-trace-ar.mp3
instruction-word-ru.mp3
instruction-word-ar.mp3
instruction-match-ru.mp3
instruction-match-ar.mp3
instruction-review-ru.mp3
instruction-review-ar.mp3
```

Назначение файлов:

- `listen` — послушай букву;
- `find` — найди букву;
- `trace` — обведи букву;
- `word` — послушай слово;
- `match` — выбери значение слова;
- `review` — повторение изученных букв.

### Правила записи и имён файлов

- используйте формат `.mp3`;
- используйте только маленькие английские буквы;
- используйте дефисы вместо пробелов;
- не используйте русские буквы в имени файла;
- имя должно совпадать полностью, включая дефисы;
- одна запись должна содержать одну короткую фразу;
- не добавляйте музыку и музыкальные эффекты.

Правильно:

```text
letter-jeem-name.mp3
```

Неправильно:

```text
Letter-Jeem-Name.mp3
letter-jeem-name 1.mp3
letter_jeem_name.mp3
```

Файлы `letter-<id>-sound.mp3` зарезервированы для отдельного упражнения на
звук буквы. Сейчас для основного прослушивания названия достаточно файла
`letter-<id>-name.mp3`.

### Минимальный тест

Для первой проверки достаточно добавить три файла:

```text
public/audio/letter-jeem-name.mp3
public/audio/praise-correct-ru.mp3
public/audio/praise-again-ru.mp3
```

После этого откройте урок буквы ج, нажмите прослушивание, выберите правильный
ответ и проверьте повторную попытку.

Рекомендуемые записи (фусха):
- имя каждой буквы (بَاء، تَاء، ثَاء…);
- звук буквы с фатхой (بَ، تَ، ثَ…);
- слова-примеры (بَاب، تَمْر، ثَلْج…);
- похвала: «أحسنتَ» / «أحسنتِ», «ممتاز»;
- подсказки: «Попробуй ещё раз», «Посмотри внимательно».

Качество: телефон в тихой комнате, ткань на отражающих поверхностях — достаточно.

## Как добавить новую букву

Всё в `src/data/letters.ts`. Буква описывается:
- `body` — осевая линия «тела» в системе `viewBox 0 0 320 320`
  (по ней рисуется буква и по ней ведёт палец ребёнок);
- `dots` — координаты точек (над/под телом);
- `nameAr`, `nameRu`, `ttsName`, `ttsSound`, `dotCount`, `dotSide`.

Добавьте объект в массив `letters` — грядка и урок появятся автоматически.

## Установка на телефон (PWA)

Service worker и «установка на экран» требуют **HTTPS** (или `localhost`).
То есть на телефоне по локальному `http://192.168.x.x` приложение
запустится, но установка/офлайн могут не активироваться.

Варианты:
- **Vercel / Netlify / GitHub Pages** — залить `dist/` после `npm run build`;
- **Cloudflare Pages**;
- туннель (ngrok / cloudflared) на время разработки.

После HTTPS-деплоя: откройте сайт в Chrome/Safari → «Добавить на главный экран».

## Известные ограничения (Фаза 1)

- Литеральный порядок/направление обводки пока оценивается мягко (без строгой
  каллиграфии) — специально, чтобы малыши не расстраивались.
- Для арабского текста используется системный шрифт. Для «книжного» вида
  в будущем стоит подключить шрифт Amiri/Noto Naskh локально.
- При арабском интерфейсе общий layout остаётся LTR (строки текста
  отображаются корректно). Полноценный RTL-layout — в следующих фазах.
- Иконки приложения — SVG; для «идеальной» установки можно добавить PNG 192/512.
